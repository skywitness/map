# 世界資料地圖

用世界地圖瀏覽各國資料。除了純地圖頁，目前有以下資料主題，在頂列依分類放在下拉選單裡：

- **社會**：人口、生育率與高齡化（總生育率、65 歲以上人口比例、扶老比、出生數，1950–2100 含推估；點國家看人口金字塔）、健康（平均壽命、嬰幼兒死亡率、醫療支出與自付比例、醫師、護理人員與病床數）、疾病（各國首要死因、慢性病過早死亡、癌症死亡率、糖尿病、肥胖、愛滋、結核病、瘧疾、死因結構）、教育（受教育年數、高等教育在學率、教育支出、識字率）、飲食（熱量、蛋白質、脂肪、動物性食物占熱量、各類食物的人均供給量、營養不足人口比例）、住宅（公寓住戶比例、自有住宅率、平均每戶人數、居住擁擠率、住房負擔過重率、都市貧民窟人口比例；住宅類型、擁擠與負擔只有歐洲與部分 OECD 國家）、宗教（各國的主要宗教、最大宗教的比例、無宗教信仰比例、宗教多樣性）、貧富差距（吉尼係數、所得最高 10% 與最低 50% 的份額、極端貧窮）、性別平等（性別不平等指數、女性勞參率、女性國會議員比例、性別薪資差距）、治安與司法（故意殺人率，含女性與男性被害人、法治分數）、諾貝爾獎（依出生地、以今天的國界計算的得主人數與每千萬人得主數，可分六個獎項；點國家列出得主名單，例如台灣的李遠哲）
- **經濟**：人均收入、薪資與工時（平均月薪與最低工資的美元與購買力平價、每週工時、每年工時）、存款與財產（平均每人存款、存款占 GDP、每位成年人的平均財富與財富中位數、最富有 10% 與 1% 的財富占比、家庭儲蓄率、國民儲蓄率）、物價與財政（通膨率、物價水準、政府債務、財政收支、稅收占 GDP）、產業結構、工業、農業
- **國際**：貿易（國際貿易流向：點選國家，畫出它跟主要貿易夥伴之間的弧線）、移民（移民與僑民人數、收容的難民；點選國家畫出移民來源、僑民去向與難民流向的弧線）、觀光（國際旅客、觀光收入）、護照與簽證（199 本護照到各國要不要簽證，點選國家就換成那國的護照；護照實力、開放程度；台灣護照跟領事事務局的名單逐國比對）、軍事（軍費、兵力）、武裝衝突（UCDP 的戰鬥死亡、非國家衝突與單方面暴力的死亡人數，1989 年起依事件地點；以國家為一方的武裝衝突數與強度，1946 年起；地圖上畫出當年的衝突事件）、民主與自由（V-Dem 的政體分類、選舉民主、自由民主與言論自由指數，1900 年起）、國際組織（歐盟、北約、東協、WTO、APEC、G7、G20、金磚國家等 16 個組織的成員、申請、夥伴與暫停參與，拖動時間軸看北約與歐盟擴大、英國脫歐；各國參加了幾個組織；台灣以「中華台北」參加 APEC、以「臺澎金馬個別關稅領域」參加 WTO）、聯合國投票（聯合國大會記名表決中跟美國、中國或其他國家的投票一致度，以及 Bailey、Strezhnev 與 Voeten 估計的投票立場「理想點」，1946 年起；1946–1971 年中國席位上的投票放在台灣）、台灣的外交（從台灣看世界：歷年邦交國、駐外館處的位置、國人免簽與落地簽待遇）
- **能源**：發電量、氣候（二氧化碳排放）、氣溫與降雨（年平均氣溫、年降雨量、暖化；暖化可以切到 0.5° 網格，側欄有每月氣候圖）、空氣品質（PM2.5 年平均濃度、超過 WHO 指引值的人口比例、空氣污染死亡率）、水資源與森林（人均可再生水資源、水資源壓力、安全管理的飲用水、森林覆蓋率、森林面積變化）、電動車（新車電動車占比、保有量、公共充電樁、車樁比）
- **科技與交通**：AI、數位（網路、行動電話、固網寬頻）、研發與創新（研發經費占 GDP、研發經費總額、研究人員、專利申請）、交通
- **地理**：語言（各國的主要官方語言、30 種語言的使用比例、使用人數與官方地位、各國有幾種語言）、海拔（平均海拔、最高點與最低點、高地占比、沿海低地、坡度；地圖上是分層設色加地形陰影）、地震與火山（1900 年起規模 6 以上的地震，大小是規模、顏色是震源深度，可以只看某一年或累積；全新世火山、板塊邊界；各國每十年的地震次數、死亡人數與火山數）

地圖可以切換地球儀與平面、一路放大到街道，並有五種底圖配色可選。按「3D」可以把數值畫成高度：比率類指標把國家依色階分級拉高，總量類指標畫成高度與數值成正比的柱子，可以旋轉、傾斜；海拔主題的 3D 是真的立體地形（地球儀上也可以）。人口主題可以在地圖上框選範圍，估算框內人口；「人口密度」可以從國家平均切到「1 km 網格」，看每個約 1 km 的格子住多少人（JRC GHS-POP，1975–2030 每 5 年一期，跟著時間軸換期）；氣溫與降雨主題的「暖化」也可以切到「0.5° 網格」，看國內各地比 1951–1980 年熱了多少（CRU TS，每年一期）。

每個畫面右上角的「分享」可以下載地圖圖片（PNG，含標題、圖例與資料來源）、下載目前指標的 CSV（選定年份或所有年份，Excel 可直接開啟），或複製這個畫面的連結。

右上角的「中文 / EN」切換介面語言，不必重新整理；英文版的網址帶 `lang=en`，分享出去打開就是英文。

資料來源、架構與新增主題的方法見 [DESIGN.md](DESIGN.md)。

## 操作

- **搜尋國家**：中文、英文、常用別名（南韓、韓國、Korea；美國、USA；英國、UK；中國、大陸）或 ISO 代碼（TW、TWN）都找得到，打一部分或拼錯一兩個字母也可以。結果會列出目前的數值，選了之後地圖會飛到那個國家。
- **鍵盤快捷鍵**（按 `?` 或右上角的「?」看說明）：
  - `/`：搜尋
  - `←` `→`：換年份（海拔這類不隨時間變化的資料沒有時間軸）
  - 空白鍵：播放／暫停
  - `+` `−`：縮放地圖
  - `Esc`：取消選取
- **手機**：國家資料從底部抽屜拉起，可以拖到收合、半開、全開三段，往下拖到底就關閉。
- **語言**：「中文 / EN」切換，選擇記在瀏覽器裡；英文版的數字用 K、M、B、T（中文用萬、億、兆），國名與地圖上的地名也換成英文。

看過一次之後，再開啟會直接從瀏覽器的快取載入，沒有網路也能開（標題旁會顯示「離線中」，資料與地圖是上次看過的部分）。手機與桌機的瀏覽器都可以把它安裝成 App。載入速度的量測與做法見 DESIGN.md 第 13 節。

網站：https://skywitness.github.io/map/

## 開發

```bash
npm install
npm run dev
```

`public/data/` 裡已經有產生好的資料，只改前端的話不需要跑資料管線。

### 檢查英文版

```bash
npm run check:i18n
```

掃描 `src/` 的原始碼，列出英文介面會看到、卻還沒翻譯的中文（新增功能或主題後跑一次）。

```bash
npm i --no-save puppeteer-core
npm run check:en
```

用無頭 Chrome 打開英文版，逐一切換每個主題、指標、排名表、國家側欄與框選，列出畫面上剩下的中文，也檢查中英切換與 `lang=en` 的網址。需要系統的 Chrome（或設定 `CHROME_PATH`）。

## 重新產生資料

第一次使用時，先建立 Python 環境：

```bash
python -m venv pipeline/.venv
pipeline/.venv/Scripts/python -m pip install -r pipeline/requirements.txt
```

（macOS / Linux 的路徑是 `pipeline/.venv/bin/python`。）

產生資料：

```bash
npm run data                   # 全部
npm run data -- population     # 只跑人口
npm run data -- --refresh      # 忽略快取，重新下載原始資料
```

可用的步驟：`geo`、`population`、`population-grid`、`population-density-tiles`、`income`、`sectors`、`agriculture`、`electricity`、`industry`、`ai`、`transport`、`climate`、`military`、`digital`、`health`、`disease`、`diet`、`education`、`tourism`、`housing`、`trade`、`language`、`elevation`、`migration`、`religion`、`inequality`、`gender`、`wages`、`fiscal`、`innovation`、`wealth`、`temperature`、`temperature-grid-tiles`、`air-quality`、`water-forest`、`ev`、`earthquakes`、`democracy`、`taiwan-diplomacy`、`passport`、`organizations`、`un-votes`、`conflict`、`nobel`、`compact`。

`population-grid` 是框選估算用的網格人口，`elevation` 是海拔主題（USGS GMTED2010 的 1 公里 DEM，第一次會下載約 760 MB），兩個都要先有 `geo` 的國界。`disease` 第一次會向 WHO 的 API 一年一年查 2000–2023 年的死因資料，約 15 分鐘。`migration` 第一次會向 UNHCR 的 API 一年一年查 1990 年以來的難民資料，約 2 分鐘。`inequality` 第一次會下載 World Inequality Database 的整包資料（約 890 MB），`wealth` 共用同一份。

`population-density-tiles` 產生人口密度的 1 km 網格圖磚（`public/tiles/`，約 585 MB、6 萬個檔）。圖磚不進版本控制，部署時由 GitHub Actions 產生；本機要看網格才需要跑，第一次會下載 12 期 GHS-POP（共 5.8 GB），約 25 分鐘。沒跑的話，切到「1 km 網格」會顯示載入失敗、改畫國家平均。開發伺服器不監看 `public/tiles/`（檔案太多會卡住），所以產生圖磚之後要重開 `npm run dev`。做法與大小見 DESIGN.md 第 14 節。

`temperature` 是氣溫與降雨主題（CRU TS，第一次會下載月均溫與降雨約 385 MB）。`temperature-grid-tiles` 產生暖化的 0.5° 網格圖磚（`public/tiles/warming/`，約 20 MB、2.4 萬個檔），跟人口密度的網格一樣不進版本控制、部署時產生，本機約 3–5 分鐘。

國際的四個主題：`passport` 只下載一個約 690 KB 的 CSV（Passport Index 資料集，固定在 GitHub 上的某個 commit），幾秒就跑完；要換新版改 `pipeline/sources/passport_index.py` 的 `COMMIT` 與 `DATA_DATE`（`src/topics/passport.ts` 的 `DATA_DATE` 也要改，資料管線會檢查），台灣護照跟領事事務局名單的比對要先有 `taiwan-diplomacy` 的資料。`organizations` 不用下載：16 個國際組織的成員表是 `pipeline/sources/igo_members.py` 依各組織官網整理的，組織有新成員、退出或暫停時改這個檔（`CHECK_COUNTS` 的成員數也要跟著改，對不上時會報錯）；今年的狀態是跑資料管線當天的，跨年後重跑一次，時間軸才會多一年。`un-votes` 第一次會從 Harvard Dataverse 下載約 23 MB（一致度的 RData 21.7 MB、理想點的 CSV 1.4 MB），整個步驟約半分鐘。`conflict` 第一次會從 UCDP 下載約 40 MB（GED 的事件資料），之後約 25 秒。

指標檔輸出時數值會壓縮（格式見 DESIGN.md 第 3 節）。`compact` 把還沒壓縮的舊指標檔一次轉換，不需要重新下載，重複執行沒有影響。

下載的原始檔會快取在 `pipeline/.cache/`，這個資料夾不進版本控制。第一次跑全部大約要下載 3.3 GB（主要是 FAOSTAT 的貿易檔、雙邊貿易矩陣與糧食平衡表、CEPII BACI、GMTED2010 的 DEM、GHS-POP 的網格人口和 Anthropic Economic Index），世界銀行 API 比較慢，全部跑完約 30 分鐘，其中 `trade` 要讀 8.5 GB 的 FAOSTAT 雙邊貿易矩陣，約占一半。`population-density-tiles` 另外要下載其他 11 期 GHS-POP（約 5.3 GB），再多約 25 分鐘。

## 部署

推送到 `main` 後，GitHub Actions（`.github/workflows/deploy.yml`）會自動建置並發佈到 GitHub Pages，約 1–2 分鐘。
資料檔已經在版本庫裡，所以更新資料的流程是：本機執行 `npm run data`，再把 `public/data/` 的變更提交、推送。

例外是人口密度的 1 km 網格圖磚：部署流程自己產生，存在 GitHub Actions 的快取裡。產生的程式或地圖的橘色色階改了（或快取超過 7 天沒用到被清掉）才重新產生，那一次部署約多 15 分鐘；JRC 的伺服器連不上時照樣部署，用上一版的圖磚。暖化的 0.5° 網格圖磚也一樣（另一個快取，產生約 5 分鐘，CRU 的伺服器連不上時用上一版）。

Live site: https://skywitness.github.io/map/?lang=en

- **Map**: switch between globe and flat map, zoom down to street level, and choose from five basemaps. **3D** turns values into heights (or real terrain on the elevation topic). Click a country to open its panel with rankings, time series and topic details. Every map also has a **Ranking** table view.
- **Search**: type a country name in English or Chinese, a common alias (UK, USA, Korea) or an ISO code (TW, TWN). Partial names and small typos work too.
- **Keyboard shortcuts** (press `?`): `/` search, `←` `→` change year, Space play/pause, `+` `−` zoom, `Esc` clear the selection.
- **Share**: download the current map as a PNG (with title, legend and sources), download the indicator as CSV, or copy a link. The whole view, including the language (`lang=en`), is stored in the URL.
- **Area estimate**: on the population topic, draw a box on the map to estimate how many people live inside it.
- **1 km grid**: population density can switch from country averages to a grid of cells about 1 km across (JRC GHS-POP, every 5 years from 1975 to 2030, following the time slider). Warming (on the temperature topic) can likewise switch to a 0.5° grid (CRU TS, one map per year). The grid tiles are not in the repository; the deploy workflow builds and caches them.
