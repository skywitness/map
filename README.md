# 世界資料地圖

用世界地圖瀏覽各國資料。除了純地圖頁，目前有以下資料主題，在頂列依分類放在下拉選單裡：

- **社會**：人口、生育率與高齡化（總生育率、65 歲以上人口比例、扶老比、出生數，1950–2100 含推估；點國家看人口金字塔）、婚姻與家庭（男女的初婚年齡、15 歲以上有偶比例、30–34 歲未婚比例、粗結婚率、粗離婚率、非婚生子女比例、單人家戶比例，以及同性伴侶的法律地位：1989–2026 年每年年底可以結婚、有民事結合等其他全國性的承認或都沒有，各國的依據寫在附註；台灣 2019 年起可以同性結婚，亞洲第一個；點台灣看歷年的結婚、離婚對數與其中的同性伴侶）、城市（全球約 1.1 萬個城市，圓的大小是人口，1975–2030 每 5 年跟著時間軸換，縮小時只畫大城市；都市化率、住在城市的比例、最大城市占全國人口、百萬人口城市數、最大城市的人口；城市是連續的市區，不是行政區，臺北、新北、桃園、基隆連成一片算一個城市，點台灣看跟內政部縣市人口的對照）、健康（平均壽命、嬰幼兒死亡率、醫療支出與自付比例、醫師、護理人員與病床數）、疾病（各國首要死因、慢性病過早死亡、癌症死亡率、糖尿病、肥胖、愛滋、結核病、瘧疾、死因結構）、疫苗與防疫（WHO/UNICEF 估計的 DTP3、麻疹第一劑 1980 年起與第二劑、HPV 疫苗（女孩第一劑）的接種率，沒有打過任何一劑的零劑兒童；COVID-19 的確診死亡、完成基礎劑的人口比例與 The Economist 估計的超額死亡，兩種死亡用同一組分級可以對照；台灣用疾管署的五合一疫苗第三劑與 MMR 第一劑完成率、衛福部死因統計的 COVID-19 死亡，點台灣看跟疾管署通報的確診死亡的對照；WHO 的「中國」含香港、澳門與台灣通報的確診死亡）、平均身高（NCD-RisC 估計的 1896–1996 年出生的男女在 18 歲時的平均身高、比 1896 年出生的高多少、男女差距，時間軸是出生年；另有 1985–2019 年 19 歲的身高；點國家看男女的歷年身高跟世界平均與 95% 不確定區間，點台灣看跟國健署國民營養健康狀況變遷調查實測的對照）、菸酒（吸菸率含男女、人均飲酒量、各國主要喝哪一種酒）、教育（受教育年數、高等教育在學率、教育支出、識字率）、學生能力（PISA 2000–2025 的數學、閱讀、科學平均分數，低成就與高成就學生的比例，跟上一次與 2012 年比的進退步，男女差距；只收參加 2025 年的 91 個國家與經濟體，北京上海江蘇浙江這類只有部分地區參加的畫成點；點台灣看三個科目的歷次分數與臺灣 PISA 國家研究中心公布的名次）、飲食（熱量、蛋白質、脂肪、動物性食物占熱量、各類食物的人均供給量、營養不足人口比例）、住宅（公寓住戶比例、自有住宅率、平均每戶人數、居住擁擠率、住房負擔過重率、都市貧民窟人口比例；住宅類型、擁擠與負擔只有歐洲與部分 OECD 國家）、宗教（各國的主要宗教、最大宗教的比例、無宗教信仰比例、宗教多樣性）、貧富差距（吉尼係數、所得最高 10% 與最低 50% 的份額、極端貧窮）、性別平等（性別不平等指數、女性勞參率、女性國會議員比例、性別薪資差距）、治安與司法（故意殺人率，含女性與男性被害人、法治分數、監禁人口率；監禁人口率只收有開放授權資料的歐洲各國、台灣、美國、加拿大、澳洲、日本）、幸福感（《世界幸福報告》的生活評價與排名，點國家看分數由哪些因素解釋）、奧運（夏季、冬季奧運的金牌數與獎牌數，單屆與歷屆累計，每千萬人獎牌數；蘇聯、東西德等歷史隊伍分開呈現；台灣以中華台北名義參賽）、諾貝爾獎（依出生地、以今天的國界計算的得主人數與每千萬人得主數，可分六個獎項；點國家列出得主名單，例如台灣的李遠哲）
- **經濟**：人均收入、薪資與工時（平均月薪與最低工資的美元與購買力平價、每週工時、每年工時）、就業與失業（失業率、青年失業率、非正式就業比例、勞動力參與率，側欄有男女對照）、存款與財產（平均每人存款、存款占 GDP、每位成年人的平均財富與財富中位數、最富有 10% 與 1% 的財富占比、家庭儲蓄率、國民儲蓄率）、物價與財政（通膨率、物價水準、政府債務、財政收支、稅收占 GDP）、稅率（營所稅 146 個國家與地區，所得稅最高稅率與起徵點、營業稅（VAT）、勞動稅負只有 OECD 會員國；台灣依所得稅法與財政部的公告，側欄有綜合所得稅級距與起徵點的換算）、外匯存底與外債（外匯存底含黃金、可支應進口月數、外債占 GDP、經常帳占 GDP）、股市規模（上市公司市值占 GDP、市值、上市公司家數）、房價與居住負擔（扣掉物價後房價 5 年、10 年的漲跌，房價所得比、房價租金比（2015 年 = 100 的指數），實質房租的漲跌；各國只能比變化，不能比房價高低；點台灣看內政部的房價所得比倍數與六都的房貸負擔率）、產業結構、工業、農業、關鍵礦產（稀土、鋰、鈷、鎳、石墨、鎵等 17 種礦產的各國產量、占全球比例與蘊藏量；台灣不是生產國）、便利商店與連鎖品牌（7-Eleven、全家、Lawson、麥當勞、星巴克、肯德基、Subway、IKEA、Costco 與所有便利商店在 OpenStreetMap 上的每百萬人店數與店數，放大後畫出選定品牌的每一家店；OSM 不是官方店數，跟公司公布的店數比對涵蓋率，寫在滑過國家的說明與側欄，例如台灣的 7-Eleven 每百萬人 257 家、全家 157 家，都是世界最多）
- **國際**：貿易（國際貿易流向：點選國家，畫出它跟主要貿易夥伴之間的弧線）、移民（移民與僑民人數、收容的難民；點選國家畫出移民來源、僑民去向與難民流向的弧線）、援助與僑匯（政府開發援助：援助國的 ODA 金額與占 GNI 比例〔對照 0.7% 目標〕、受援國收到的援助、占 GNI 與每人金額，點選國家畫出援助對象或援助來源的弧線，多邊機構列在側欄；僑匯的收入、占 GDP 與支出，含台灣）、觀光（國際旅客、觀光收入）、護照與簽證（199 本護照到各國要不要簽證，點選國家就換成那國的護照；護照實力、開放程度；台灣護照跟領事事務局的名單逐國比對）、軍事（軍費、兵力）、武裝衝突（UCDP 的戰鬥死亡、非國家衝突與單方面暴力的死亡人數，1989 年起依事件地點；以國家為一方的武裝衝突數與強度，1946 年起；地圖上畫出當年的衝突事件）、民主與自由（V-Dem 的政體分類、選舉民主、自由民主與言論自由指數，1900 年起）、政府治理（世界銀行全球治理指標 WGI 的發聲與課責、政治穩定、政府效能、法規品質、法治、貪腐控制，0–100 分，1996 年起；點國家看六個面向跟世界中位數的對照、估計值、標準誤與 90% 信賴區間；國際透明組織的清廉印象指數不准改作，沒有用）、國際組織（歐盟、北約、東協、WTO、APEC、G7、G20、金磚國家等 16 個組織的成員、申請、夥伴與暫停參與，拖動時間軸看北約與歐盟擴大、英國脫歐；各國參加了幾個組織；台灣以「中華台北」參加 APEC、以「臺澎金馬個別關稅領域」參加 WTO）、聯合國投票（聯合國大會記名表決中跟美國、中國或其他國家的投票一致度，以及 Bailey、Strezhnev 與 Voeten 估計的投票立場「理想點」，1946 年起；1946–1971 年中國席位上的投票放在台灣）、台灣的外交（從台灣看世界：歷年邦交國、駐外館處的位置、國人免簽與落地簽待遇）
- **能源**：發電量、發電廠地圖（全球 20 MW 以上的電廠，顏色是能源、大小是裝置容量，可以打開興建中、規劃中與已退役的；各國各能源的裝置容量）、太陽能與風能潛力（太陽光電每 kWp 每天的發電量、離地 100 公尺的風功率密度、近岸海域的風能；可以切到約 2 km 網格，看得到台灣海峽的風場）、氣候（二氧化碳排放）、氣溫與降雨（年平均氣溫、年降雨量、暖化；暖化可以切到 0.5° 網格，側欄有每月氣候圖）、空氣品質（PM2.5 年平均濃度、超過 WHO 指引值的人口比例、空氣污染死亡率）、水資源與森林（人均可再生水資源、水資源壓力、安全管理的飲用水、森林覆蓋率、森林面積變化）、電動車（新車電動車占比、保有量、公共充電樁、車樁比）

地圖可以切換地球儀與平面、一路放大到街道，並有五種底圖配色可選。按「3D」可以把數值畫成高度：比率類指標把國家依色階分級拉高，總量類指標畫成高度與數值成正比的柱子，可以旋轉、傾斜；海拔主題的 3D 是真的立體地形（地球儀上也可以）。人口主題可以在地圖上框選範圍，估算框內人口；「人口密度」可以從國家平均切到「1 km 網格」，看每個約 1 km 的格子住多少人（JRC GHS-POP，1975–2030 每 5 年一期，跟著時間軸換期）；氣溫與降雨主題的「暖化」也可以切到「0.5° 網格」，看國內各地比 1951–1980 年熱了多少（CRU TS，每年一期）；太陽能與風能潛力也可以切到「約 2 km 網格」（Global Solar Atlas、Global Wind Atlas）；夜間燈光一打開就是「約 500 m 網格」（EOG 的 VIIRS 年度合成，2013、2016、2020、2024 四期），網格底下鋪一層夜色，任何底圖上都是夜景；航運與港口的「航運密度」是約 5 km 的網格（世界銀行與 IMF 用 2015–2021 年的 AIS 船位算出），看得到全球的航道。

每個畫面右上角的「分享」可以下載地圖圖片（PNG，含標題、圖例與資料來源）、下載目前指標的 CSV（選定年份或所有年份，Excel 可直接開啟），或複製這個畫面的連結。

右上角的「中文 / EN」切換介面語言，不必重新整理；英文版的網址帶 `lang=en`，分享出去打開就是英文。

資料來源、架構與新增主題的方法見 [DESIGN.md](DESIGN.md)。

## 操作

- **搜尋國家**：中文、英文、常用別名（南韓、韓國、Korea；美國、USA；英國、UK；中國、大陸）或 ISO 代碼（TW、TWN）都找得到，打一部分或拼錯一兩個字母也可以。結果會列出目前的數值，選了之後地圖會飛到那個國家。
- **鍵盤快捷鍵**（按 `?` 或右上角的「?」看說明）：
  - `/`：搜尋
  - `←` `→`：換年份（海拔這類不隨時間變化的資料沒有時間軸）
  - 空白鍵：播放／暫停
  - `+` `−`：縮放地圖
  - `Esc`：取消選取
- **手機**：國家資料從底部抽屜拉起，可以拖到收合、半開、全開三段，往下拖到底就關閉。
- **語言**：「中文 / EN」切換，選擇記在瀏覽器裡；英文版的數字用 K、M、B、T（中文用萬、億、兆），國名與地圖上的地名也換成英文。

看過一次之後，再開啟會直接從瀏覽器的快取載入，沒有網路也能開（標題旁會顯示「離線中」，資料與地圖是上次看過的部分）。手機與桌機的瀏覽器都可以把它安裝成 App。載入速度的量測與做法見 DESIGN.md 第 13 節。

網站：https://skywitness.github.io/map/

## 開發

```bash
npm install
npm run dev
```

`public/data/` 裡已經有產生好的資料，只改前端的話不需要跑資料管線。

### 檢查英文版

```bash
npm run check:i18n
```

掃描 `src/` 的原始碼，列出英文介面會看到、卻還沒翻譯的中文（新增功能或主題後跑一次）。

```bash
npm i --no-save puppeteer-core
npm run check:en
```

用無頭 Chrome 打開英文版，逐一切換每個主題、指標、排名表、國家側欄與框選，列出畫面上剩下的中文，也檢查中英切換與 `lang=en` 的網址。需要系統的 Chrome（或設定 `CHROME_PATH`）。

## 重新產生資料

第一次使用時，先建立 Python 環境：

```bash
python -m venv pipeline/.venv
pipeline/.venv/Scripts/python -m pip install -r pipeline/requirements.txt
```

（macOS / Linux 的路徑是 `pipeline/.venv/bin/python`。）

產生資料：

```bash
npm run data                   # 全部
npm run data -- population     # 只跑人口
npm run data -- --refresh      # 忽略快取，重新下載原始資料
```

`population-grid` 是框選估算用的網格人口，`elevation` 是海拔主題（USGS GMTED2010 的 1 公里 DEM，第一次會下載約 760 MB），兩個都要先有 `geo` 的國界。`disease` 第一次會向 WHO 的 API 一年一年查 2000–2023 年的死因資料，約 15 分鐘。`migration` 第一次會向 UNHCR 的 API 一年一年查 1990 年以來的難民資料，約 2 分鐘。`inequality` 第一次會下載 World Inequality Database 的整包資料（約 890 MB），`wealth` 共用同一份。

`population-density-tiles` 產生人口密度的 1 km 網格圖磚（`public/tiles/`，約 585 MB、6 萬個檔）。圖磚不進版本控制，部署時由 GitHub Actions 產生；本機要看網格才需要跑，第一次會下載 12 期 GHS-POP（共 5.8 GB），約 25 分鐘。沒跑的話，切到「1 km 網格」會顯示載入失敗、改畫國家平均。開發伺服器不監看 `public/tiles/`（檔案太多會卡住），所以產生圖磚之後要重開 `npm run dev`。做法與大小見 DESIGN.md 第 14 節。

`submarine-cables` 第一次會向 TeleGeography 的 API 一條一條抓 713 條電纜的明細（每次間隔 0.4 秒，約 18 分鐘、共約 1.6 MB），之後用快取；要更新加 `--refresh`。

`temperature` 是氣溫與降雨主題（CRU TS，第一次會下載月均溫與降雨約 385 MB）。`temperature-grid-tiles` 產生暖化的 0.5° 網格圖磚（`public/tiles/warming/`，約 20 MB、2.4 萬個檔），跟人口密度的網格一樣不進版本控制、部署時產生，本機約 3–5 分鐘。

`typhoons` 是颱風與颶風主題（NOAA IBTrACS，333 MB；NCEI 單一連線很慢，見 DESIGN.md 第 8 節第 58 點）。`power-plants` 下載 Global Energy Monitor 公開地圖的資料檔（約 62 MB）。`renewables` 是太陽能與風能潛力的各國平均，`renewables-grid-tiles` 產生它的約 2 km 網格圖磚（`public/tiles/renewables-solar/`、`renewables-wind/`，約 9 MB、1,150 個檔，部署時產生）；兩個都要下載 Global Solar Atlas 的 PVOUT（345 MB）與 Global Wind Atlas 檔案裡 0.02° 的縮小版（182 MB，只抓那一段），本機約 2–3 分鐘。`wildfires` 下載 GWIS 的燒毀面積（約 12 MB），第一次另外向 GWIS 查各國面積，約 6 分鐘。

`night-lights` 是夜間燈光主題的各國統計與燈光最多的地區：第一次會從 Zenodo 下載 2013–2024 年的 VIIRS 夜間燈光（EOG Annual VNL V2 的轉存，12 個檔、共約 820 MB；Zenodo 慢的時候每條連線只有約 25 KB/s，分段平行下載，最慢約 20 分鐘），人口用 GHS-POP 2015、2020、2025 三期（跟 `population-density-tiles` 共用快取），另外下載 Natural Earth 的第一級行政區（約 41 MB），要先有 `geo` 的國界，統計約 7 分鐘（算完存在快取，只改輸出時幾秒）。`night-lights-tiles` 產生它的約 500 m 網格圖磚（`public/tiles/night-lights/`，4 期、約 106 MB、2.1 萬個檔，部署時產生），本機約 2.5 分鐘。

`house-prices` 是房價與居住負擔主題：下載 OECD 的房價指標（約 17 MB）、BIS 的住宅價格（約 0.3 MB）、內政部不動產資訊平台的住宅價格指數與房價負擔能力指標（API，有時要等幾十秒）、主計總處的消費者物價（XML 約 27 MB），之後用快取約 10 秒。

`cities` 是城市主題：從 JRC 下載 GHSL Urban Centre Database 2025（一般屬性 6.6 MB、多時期城市 35 MB）與各國依城鄉程度的人口（1.5 MB），向 Wikidata 查人口 3 萬以上的地點（兩次查詢約 1 分鐘）與城市的中文名稱（約 130 次查詢），再向內政部戶政司的開放資料 API 查各村里人口（4 次）；第一次約 2.5 分鐘，之後用快取約 3 秒。

`vaccination` 是疫苗與防疫主題：向 WHO GHO 查 5 個疫苗涵蓋率指標（各約 3 MB）、世界銀行的 2 個序列，下載 Our World in Data 的 COVID-19 資料（compact.csv，約 180 MB）、OWID 封存的 JHU 累計死亡（1.6 MB）與 The Economist 超額死亡模型的兩個輸出檔（約 11 MB，固定在 2024-06-18 的 commit），衛福部死因統計跟 `disease` 共用快取；第一次約 1 分鐘，之後約 15 秒。台灣的常規疫苗完成率是照疾管署各年 PDF 的圖抄進 `pipeline/sources/cdc_tw.py` 的，每年 PDF 出新版時要補一年。

`height` 是平均身高主題：從 NCD-RisC 下載成人身高（2.4 MB）與兒童青少年身高（4.6 MB 的 zip）。NCD-RisC 的伺服器常回 HTTP 421 或傳到一半斷線，Python 的連線也常被重設，所以用 curl 下載、依 Content-Length 檢查大小並續傳（要有 curl，Windows 10 以後內建）；WPP 的年齡別人口跟其他主題共用快取。第一次約 1 分鐘，之後約 10 秒。台灣對照用的國健署實測數字是照成果報告的表抄進 `pipeline/sources/nahsit.py` 的，報告出新版時要手動更新。

`taxes` 是稅率主題：向 OECD 的 SDMX API 下載公司稅、個人所得稅最高稅率與勞動稅負（3 個 CSV，共約 16 MB），約 10 秒；加值型營業稅的標準稅率與台灣的稅率、級距、扣除額寫在 `pipeline/sources/oecd_tax.py`、`tw_tax_law.py`（出處見 DESIGN.md 第 8 節第 72 點），台灣的平均薪資用主計總處（跟薪資與工時主題同一個快取）。

`chain-stores` 是便利商店與連鎖品牌主題：向 OpenStreetMap 的 Overpass API 發 27 個查詢（9 個品牌的 `brand:wikidata` 各一個、沒有標 QID 的店依名稱比對 6 種店型各一個、所有便利商店分 12 個經度帶），一次一個、只要 9 個欄位的 CSV，共約 72 MB；公用伺服器忙的時候常回 502，會等一下再試（30 秒起加倍），2026-10-26 全部跑完約 2.5 小時。結果存在快取，之後約 1 分鐘（約 95 萬個點判斷國家）。公司公布的店數寫在 `pipeline/sources/chain_official.py`（出處見 DESIGN.md 第 8 節第 75 點），有新的年報時手動更新。要先有 `geo` 的國界。

`shipping` 是航運與港口主題：下載 UNCTAD Data Hub 的 6 個整包檔（7z 壓縮的 CSV，共約 2.5 MB，用 `py7zr` 解開，`pipeline/requirements.txt` 已列）、NGA 的 World Port Index（3.5 MB，NGA 的 CDN 常隨機回 503，會等一下再試）與臺灣港務公司的貨櫃裝卸量，約 5 秒。主要港口自己公布的吞吐量寫在 `pipeline/sources/port_teu.py`（出處見 DESIGN.md 第 8 節第 76 點），台灣四港會跟臺灣港務公司的開放資料比對，對不上時報錯。`shipping-density-tiles` 產生航運密度的約 5 km 網格圖磚（`public/tiles/ship-density/`，234 張、約 4.4 MB，部署時產生）：第一次下載世界銀行的 Global Shipping Traffic Density（535 MB），用 GDAL 的 `/vsizip/` 依序讀 9.8 GB 的原始網格並平均成 0.02°（本機約 7 分鐘，結果存在快取），之後約 12 秒。

`governance` 是政府治理主題：向世界銀行 API 查 WGI 六個面向各 6 個序列（分數、信賴區間上下限、估計值、標準誤、來源數，36 次查詢、共約 52 MB），第一次約 1 分鐘，之後用快取約 1 秒；法治的序列跟 `crime` 共用快取。WGI 每年 9 月改版，要更新加 `--refresh`。

`pisa` 是學生能力主題：從 OECD 的 StatLink 下載《PISA 2025 Results (Volume I)》附錄的兩個 Excel（約 2.8 MB），約 1 秒；臺灣的分數會跟臺灣 PISA 國家研究中心公布的數字比對，對不上時會報錯。

`marriage` 是婚姻與家庭主題：下載聯合國 World Marriage Data 2019（約 26 MB）、Eurostat 的 4 個資料集、OECD Family Database 的 2 個 Excel、內政部戶政司的 5 個歷年統計表與內政部統計查詢網的婚姻狀況，再從 UNdata 一國一頁抓結婚、離婚對數（第一次約 220 頁網頁，每頁間隔 0.3 秒，約 4 分鐘；UNdata 舊的下載介面已經停用，見 DESIGN.md 第 8 節第 69 點），之後用快取約 45 秒。同性伴侶的法律地位是 `pipeline/sources/same_sex_unions.py` 依維基百科整理的表，有國家修法時改這個檔。

`aid` 是國際援助與僑匯主題：向 OECD 的 SDMX API 下載 DAC1（各援助國的 ODA、占 GNI 與組成）與 DAC2A（援助國 × 受援國的 ODA，1960 年起，含多邊機構；3 個 CSV 共約 75 MB），向世界銀行 API 查 3 個僑匯序列，台灣讀中央銀行的國際收支（跟 `tourism`、`reserves` 共用快取）；第一次約 30 秒，之後用快取約 3 秒。DAC 每年 4 月公布前一年的初步數字、12 月公布完整的數字，更新時加 `--refresh`。

國際的四個主題：`passport` 只下載一個約 690 KB 的 CSV（Passport Index 資料集，固定在 GitHub 上的某個 commit），幾秒就跑完；要換新版改 `pipeline/sources/passport_index.py` 的 `COMMIT` 與 `DATA_DATE`（`src/topics/passport.ts` 的 `DATA_DATE` 也要改，資料管線會檢查），台灣護照跟領事事務局名單的比對要先有 `taiwan-diplomacy` 的資料。`organizations` 不用下載：16 個國際組織的成員表是 `pipeline/sources/igo_members.py` 依各組織官網整理的，組織有新成員、退出或暫停時改這個檔（`CHECK_COUNTS` 的成員數也要跟著改，對不上時會報錯）；今年的狀態是跑資料管線當天的，跨年後重跑一次，時間軸才會多一年。`un-votes` 第一次會從 Harvard Dataverse 下載約 23 MB（一致度的 RData 21.7 MB、理想點的 CSV 1.4 MB），整個步驟約半分鐘。`conflict` 第一次會從 UCDP 下載約 40 MB（GED 的事件資料），之後約 25 秒。

指標檔輸出時數值會壓縮（格式見 DESIGN.md 第 3 節）。`compact` 把還沒壓縮的舊指標檔一次轉換，不需要重新下載，重複執行沒有影響。

下載的原始檔會快取在 `pipeline/.cache/`，這個資料夾不進版本控制。第一次跑全部大約要下載 3.3 GB（主要是 FAOSTAT 的貿易檔、雙邊貿易矩陣與糧食平衡表、CEPII BACI、GMTED2010 的 DEM、GHS-POP 的網格人口和 Anthropic Economic Index），世界銀行 API 比較慢，全部跑完約 30 分鐘，其中 `trade` 要讀 8.5 GB 的 FAOSTAT 雙邊貿易矩陣，約占一半。`population-density-tiles` 另外要下載其他 11 期 GHS-POP（約 5.3 GB），再多約 25 分鐘。`semiconductors` 跟 `trade` 共用 BACI 的快取（讀一次約 2 分鐘），`minerals` 第一次會下載 USGS MCS 2020–2026 版各礦種章節的 PDF（約 110 個、36 MB）。

```bash
npm run build
```

輸出在 `dist/`，可以放到任何靜態主機。

## 部署

推送到 `main` 後，GitHub Actions（`.github/workflows/deploy.yml`）會自動建置並發佈到 GitHub Pages，約 1–2 分鐘。
資料檔已經在版本庫裡，所以更新資料的流程是：本機執行 `npm run data`，再把 `public/data/` 的變更提交、推送。

例外是人口密度的 1 km 網格圖磚：部署流程自己產生，存在 GitHub Actions 的快取裡。產生的程式或地圖的橘色色階改了（或快取超過 7 天沒用到被清掉）才重新產生，那一次部署約多 15 分鐘；JRC 的伺服器連不上時照樣部署，用上一版的圖磚。暖化的 0.5° 網格圖磚也一樣（另一個快取，產生約 5 分鐘，CRU 的伺服器連不上時用上一版），太陽能與風能的約 2 km 網格圖磚也是（再一個快取，產生約 3 分鐘），夜間燈光的約 500 m 網格圖磚也是（再一個快取，從 Zenodo 下載 4 年約 270 MB 再產生，第一次部署約 3.5 分鐘，Zenodo 連不上時用上一版），航運密度的約 5 km 網格圖磚也是（再一個快取，從世界銀行下載 535 MB 再產生，約 10 分鐘，連不上時用上一版）。

- **1 km grid**: population density can switch from country averages to a grid of cells about 1 km across (JRC GHS-POP, every 5 years from 1975 to 2030, following the time slider). Warming (on the temperature topic) can likewise switch to a 0.5° grid (CRU TS, one map per year), and solar and wind potential to a ~2 km grid (Global Solar Atlas, Global Wind Atlas). Night lights open on a ~500 m grid (EOG annual VIIRS composites for 2013, 2016, 2020 and 2024) drawn over a dark night backdrop, so it reads as a night view on any basemap. The grid tiles are not in the repository; the deploy workflow builds and caches them.
